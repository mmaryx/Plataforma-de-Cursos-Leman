# Plataforma-de-Cursos-Leman
Projeto acadêmico de uma plataforma de cursos online, desenvolvido na disciplina Fio Condutor. O sistema permite o gerenciamento de cursos, matrículas, conteúdos e progresso dos estudantes. Este repositório reúne a documentação e as implementações de API REST, mensageria, GraphQL e API Gateway.
